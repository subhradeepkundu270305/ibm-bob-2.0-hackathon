## Segment 2 — Bob 2.0 In Action
**⏱ 0:30 – 1:15 · 45 seconds · Screen: Live VS Code session · LIVE ACTION**

> *[Screen recording: VS Code open on the raw URL Shortener `index.js` — 400+ lines,
> no comments, no structure visible. Bob sidebar is open on the right.]*

**NARRATOR (V.O.):**

"This is our testbed: a real URL Shortener monolith — one file, zero documentation,
zero tests, and a cyclomatic complexity score of 18.

Watch what happens when we drop IBM Bob 2.0 onto it."

> *[TYPE into Bob chat: "Analyze this entire codebase and generate an end-to-end

"In seconds, Bob maps the entire request lifecycle — every route, every data flow,
every risk surface — and saves it as a living architecture diagram."

"Then it writes the missing documentation — not generic boilerplate, but descriptions
anchored to what the code actually does."

> *[CUT TO: `subhradeep/04_code_smells_audit.png` — `docs/code-smells.md` open,
> showing the 5-smell ranked table with line references.]*

"And before we touch a single line, Bob produces a ranked code smell audit —
five critical issues, every one mapped to exact line numbers, ordered by severity.
SQL injection: Critical. Duplicated validation: High. Arrow-of-doom nesting: High."

## Segment 3 — Interactive Dashboard Walkthrough
**⏱ 1:15 – 2:30 · 75 seconds · Screen: Live Dashboard · LIVE ACTION**

> *[Screen recording: Open `dashboard/index.html` in browser — the Legacy Code X-Ray
> dashboard fills the screen. Show the header: "Legacy Code X-Ray — Powered by

> "✓ Transformation Complete".]*

**NARRATOR (V.O.):**

"This is the Legacy Code X-Ray dashboard — generated by Bob to make the transformation

"After Bob: six clean modules — routes, services, validators, utilities — cyclomatic
complexity down from 18 to 3, duplication eliminated entirely, every SQL query
parameterised, test coverage from zero to over 90 percent, and full JSDoc plus a

> *[Scroll down to the Code Diff Viewer section — show the SQL before/after diff tab,
> referencing `partho/05_refactor_sql_security.png`.]*

"Bob didn't just flag the SQL injection risk — it fixed it. Every string-concatenated
query replaced with parameterised placeholders. Here's the exact diff — before on
the left, after on the right. One Bob prompt. Zero regressions."

"Bob generated 21 test assertions across five suites — each one running against an
in-memory database to guarantee isolation. Every test green before the next refactor
step was allowed to proceed. Safe, stepwise, verified."
