## Slide 4 — Real-World Demonstration

**Layout:** Full-width · Top: toggle bar · Bottom: two 3-column metric grids (Before / After)

**Headline:**
> URL Shortener Testbed — Before vs. After

**Sub-headline:**
> A real monolith. Real Bob sessions. Measurable, verified results.

**Before/After Toggle visual (reference `priya/02_dashboard_toggle.png`):**
```
[ ⚠ Before (Legacy) ] ●────────○ [ ✓ After (Bob Refactored) ]
```

**Metrics grid:**

| Metric | ⚠ Before | ✅ After |
|---|---|---|
| Codebase Structure | 1 God File (`index.js` · 400+ lines) | 6 Modular files (routes · services · validators · utils) |
| Cyclomatic Complexity | **Score 18** — 7-level deep nesting | **Score 3** — guard clauses, single-responsibility fns |
| Code Duplication | **28%** — validation copied across routes | **0%** — `validateUrl()` extracted, one source of truth |
| Security Posture | **High Risk** — raw SQL injection on all 5 queries | **Safe** — parameterised placeholders on every query |
| Test Coverage | **0%** — no test file existed | **90%+** — 21 assertions across 5 isolated suites |
| Documentation | **None** — no docstrings, no README | **Full JSDoc + README** — 8-section living document |

**Code diff callout (reference `partho/05_refactor_sql_security.png`):**
```js
// BEFORE — SQL Injection Risk
var sql = "UPDATE urls SET original_url = '" + targetUrl
        + "' WHERE code = '" + shortCode + "'";
db.run(sql, function(err) { … });

// AFTER — Parameterised, Safe
db.run("UPDATE urls SET original_url = ? WHERE code = ?",
  [targetUrl, shortCode],
  function(err) { if (err) { return res.status(500).send(…); } });
```

**Architecture diagram callout:**
> *Before:* Single-file monolith — all concerns inline
> *After:* `routes/` · `src/services/` · `src/validators/` · `src/utils/` — full MVC separation
